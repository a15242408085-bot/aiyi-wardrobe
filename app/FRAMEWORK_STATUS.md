# 爱衣橱功能状态

更新于 2026 年 10 月 16 日。

## 当前实现

- 基于 Wardrowbe 的 Next.js、FastAPI、衣物及搭配数据结构，保留原 MIT 许可证。
- 六个中文页面：我的衣橱、搭配工作台、试衣间、模特与 360、我的身材、功能与设置。
- 本机 SQLite 模式不依赖 Docker、PostgreSQL 或 Redis；原生产路径保留。一键启动只监听 `127.0.0.1`。
- 衣物真实上传、图片读取、编辑、筛选、喜欢、删除；上衣与下装可手动组合并保存。
- 识别任务生成候选，支持编辑、取消选择与幂等确认入库。可选生成干净单品图，按上衣、外套、下装、鞋、包每类最多一件；部分生成失败时保留原图或裁剪图，仍可确认其他候选。
- 已入库衣物可单独生成单品图，对照原图后显式确认应用。应用操作幂等；衣物原图在生成后发生变化会拒绝覆盖，提示重新生成。
- 模特库保存用户上传的真实人物照片和名称；试穿可以选择库内模特，也可以另传人物照片。无默认假人或 WOO 图片资源。
- 试穿支持上衣、外套、下装、鞋、包共 1–5 件，每类一件；生成结果持久化、分页查看与下载。
- 模特图和试穿结果可提交云端转身任务。也可不配置云端服务，直接导入用户 MP4/MOV，在本机提取 61 帧并以拖动、滑条或自动播放查看。
- 转身展示采用视频帧序列，不包含真实 3D 人体网格。导入与生成均默认不去绿幕，用户勾选后才做绿色背景处理。
- 识别、图片、视频三个服务分别设置地址、模型与密钥。识别/图片支持 OpenAI、OpenAI 兼容服务、Gemini 原生；视频支持 WaveSpeed。
- 衣物识别设置新增 DeepSeek 专用选项，默认 `https://api.deepseek.com` 与 `deepseek-flash`；不用于图片或视频生成。官方识别密钥已加密保存，已完成一次真实商品图识别和确认入库。
- 任务与进度持久化，刷新可恢复。已保存远端任务编号或本地视频的转身任务可安全续查或继续抽帧；中断的图片生成不会自动再次付费提交。
- API 密钥按用户、服务隔离并在后端加密保存。模型列出和接口连通不被当作实际生成成功。

2026-10-16 已在用户要求下，用 IDM-VTON 官方仓库的真人样例 `human/00035_00.jpg` 和商品图 `cloth/04469_00.jpg`，在网页完成识别 → 确认入库 → 保存模特 → 选衣试穿 → 刷新恢复 → 下载。图片质量设置为 high。首次图片调用约 94.7 秒后收到 HTTP 502；保留失败证据后显式重试原任务一次，约 70.9 秒成功。下载文件与服务端保存结果的 SHA-256 一致。实际扣费未核对。

视觉检查：人物脸部特征、卷发与正面站姿基本保留，V 领交叠方向、侧系带、短袖和丝绒反光清晰，未见明显贴图或原上衣图案残留。生成图的蓝色偏深，下摆更贴身并向中间上提；构图、面部和裤腰/纽扣/口袋细节有重绘。本次只验证一组人物和一件上衣，不代表复杂图案、多件搭配或所有体型都已通过。

衣物“实测示例 · 深蓝色丝绒交叉V领系带短袖上衣”、模特“实测模特 · IDM 00035”与试穿结果保留在当前账户。输入、来源、首次失败记录、完成任务记录、原样输出及截图存于 `backend/.local/qa/real-photo-tryon-20261016/`，只作内部实测素材。此前假人测试仅作为历史接口验证，不是本次效果依据。

第二组实测为用户上传的 819×1211 五件搭配拼图与 AI 生成的成年中国女生全身模特图。首次识别五件分类正确，但原有紧框裁剪切掉袖口、裤脚和包底。通用裁剪增加四周安全边距后，重新调用识别确认五件，未生成额外商品图；旧的未确认测试任务已留证并清理，没有重复入库。新裁剪主体完整，鞋图上缘仍有少量邻件残留。`gpt-image-2` 高质量五件换装一次调用约 131.6 秒成功，输出 1024×1536 JPEG，刷新及下载通过。包的自然握持与外套叠穿可用，但包形变得更竖、翻盖更大更圆，牛仔裤更厚挺平整，鞋面条纹及鞋底细节改绘。衣物/虚拟模特以“拼图实测”标记保留，证据和提示词位于 `backend/.local/qa/collage-chinese-model-20261016/`。模特底图来自内置 imagegen；此次没有实现按用户围度生成模特的产品功能。

此前版本已在浏览器验证基础登录、衣物上传/编辑/删除、搭配保存、模特预选及本地视频 61 帧的滑条/拖动/播放/刷新。390 像素宽度未见横向溢出或损坏图片。单品图生成与云端视频效果仍需真实数据验收。

此前本地视频 QA 创建的两条模特/转身记录及 65 个媒体文件已移除，与本次保留的真人实测记录不同。最新配置为 DeepSeek 识别与原有 `gpt-image-2` 图片服务已配置，图片质量 high，视频服务仍未配置。新提供的 GPT 密钥未列出图片模型，未用于替换现有图片密钥。
