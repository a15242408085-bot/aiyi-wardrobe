关于 AI 试穿

体验版展示的是此前已经生成的真实案例。更换你自己的衣物后，可以组合并保存搭配。

自动识别衣物、生成新的真人试穿图、生成转身视频，需要连接完整版的 AI 服务。

这个文件不连接云端 AI，也不含任何 API 密钥。

试穿图用于观察搭配外观，具体尺码和穿着松紧仍需要实际试穿确认。

我的衣物存在哪里？

你添加的衣物、人物照片和搭配只保存在当前浏览器，不会自动同步到其他设备。

在「我的衣橱」底部点击「导出备份」，会得到一份 JSON 备份文件。换浏览器或电脑时，再点击「导入备份」即可恢复。

清理浏览器数据可能删除本机衣橱。若浏览器提示无法保存，请先导出备份。体验版最多保存 500 件衣物、40 张人物图、100 套搭配，图片与资料合计不超过 50 MB。

怎么发给朋友体验？

  1. 把这份 HTML 文件直接发给对方。
  2. 下载文件后，使用浏览器打开。
  3. 先看内置示例，再添加自己的照片和衣物。

转发 HTML 文件会分享内置案例。你后来添加的内容留在自己的浏览器里。要分享自己的衣橱，请同时发送导出的备份文件。

部分聊天软件只能预览文件，若按钮无法操作，请下载后用浏览器打开。
