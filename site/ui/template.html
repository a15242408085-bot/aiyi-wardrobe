关于 AI 试穿

「示例前后对比」展示内置案例。「生成 AI 试穿」会使用当时选中的人物和衣物，生成一张新的图片。

启用体验码后，点击「识别衣物」可得到待确认的衣物信息；检查后再保存到个人衣橱。生成转身视频暂未开放，本机视频播放可继续使用，导入的视频会独立保存在当前浏览器，不随 JSON 备份导出。

体验码只留在本次浏览器会话中，不会随备份导出。网页不包含服务商的 API 密钥。

试穿图用于观察搭配外观，具体尺码和穿着松紧仍需要实际试穿确认。

我的衣物存在哪里？

个人衣橱、人物照片、搭配和已保存的试穿结果留在当前浏览器，不会自动同步到其他设备。点击 AI 识别或生成时，相应照片会发送给网站的 AI 服务。任务结果可在 7 天内从服务器查询，过期后会在后续请求时清理。

在「我的衣橱」底部点击「导出备份」，会得到一份 JSON 备份文件。换浏览器或电脑时，再点击「导入备份」即可恢复。

清理浏览器数据可能删除本机衣橱。若浏览器提示无法保存，请先导出备份。体验版最多保存 500 件衣物、40 张人物图、100 套搭配，图片与资料合计不超过 50 MB。

怎么发给朋友体验？

  1. 把网页链接发给对方。
  2. 先看示例，再添加自己的照片和衣物。
  3. 有体验码时，在页面上方启用在线 AI。

转发链接会分享内置示例，你后来添加的衣物仍留在自己的浏览器。要分享自己的衣橱，请另行发送导出的备份文件。

生成期间请保留页面和网络连接。如果断线，点击「查询结果」恢复；查询不会重新生成。
